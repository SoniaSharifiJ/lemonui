# Lemon UI design-system skill

Reusable Persian RTL product-UI guidance and implementation assets based on Lemon UI.

## Latest package

Download [lemonui-design-system.zip](lemonui-design-system.zip), extract it, and install the `lemonui-design-system` folder in your agent's skills directory. The unpacked source is in [lemonui-design-system/](lemonui-design-system/); installation instructions are included there.

The v2 update adds shared CSS/JS components, offline Vazirmatn fonts, an ERP starter, contrast and single-file export scripts, and evaluation cases. It preserves the Reicon MCP-only icon policy and includes a shared moving glass menu selection surface and card/table skeleton guidance.

Reicon MCP must be connected separately. Bundled legacy illustrative SVGs have not been verified as Reicon output and must be replaced through that MCP before claiming icon-policy compliance.

Validation: official skill validator passed; 36 light/dark contrast checks passed; JavaScript syntax and offline-font export checks passed. Browser rendering and model evaluation cases were not run. See [validation/v2.json](validation/v2.json).
